# Конфигурация интерпретации методологии

## Текущая версия: 1.0

### Параметры расчёта

| Параметр | Значение | Описание |
|----------|----------|----------|
| `threshold_percent` | 70 | Порог соответствия грейду (%) |
| `hard_skills_only` | true | Учитывать только Hard-компетенции |
| `grades_order` | [Сеньор, Мидл+, Мидл, Джун+, Стажер] | Порядок проверки сверху вниз |

### Логика расчёта

```
Для каждого грейда:
  1. Берём все Hard-компетенции, где есть требование для этого грейда
  2. Считаем, сколько из них факт >= требования
  3. Доля = (соответствующие / всего с требованием) * 100%
  
Итоговый грейд = максимальный грейд, где доля >= threshold_percent
```

### Правила обработки

- **Soft-компетенции**: Исключены из расчёта
- **Пустые значения**: Игнорируются (не в числителе, не в знаменателе)
- **Формат оценок**: 0=Не знаю, 1=Знаю, 2=Использую, 3=Профи

### Возможные изменения интерпретации

При получении новой матрицы можно менять:
1. `threshold_percent` — порог (например, 60% вместо 70%)
2. `hard_skills_only` — включить Soft в расчёт
3. `excluded_competencies` — список исключаемых компетенций
4. `grade_weights` — весовые коэффициенты для компетенций
5. `minimum_critical_competencies` — обязательные компетенции для грейда
