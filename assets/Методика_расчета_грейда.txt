Методика расчета грейда по матрице компетенций
Исходные данные
Для расчета грейда используются два источника
Матрица компетенций
Содержит перечень компетенций и требуемый уровень владения каждой компетенцией для каждого грейда.
Результаты оценки сотрудника
Содержат фактический уровень владения сотрудником каждой компетенцией.
Шкала оценки компетенций
Каждая компетенция оценивается по четырехуровневой шкале:
0 — Не знаю — Не знаком с областью или не выполнял задачи такого типа
1 — Знаю — Понимает теорию, может объяснить основы
2 — Использую — Применяет на практике, решает задачи в работе, может показать примеры
3 — Профи — Применяет системно, обучает других, развивает практику
Требования к грейдам
Для каждой компетенции в матрице указан минимальный требуемый балл для каждого грейда:
• Стажер
• Джун+ / младший
• Мидл / аналитик
• Мидл+ / ведущий
• Сеньор / старший
Например, если для компетенции «Описание процессов» в грейде «Мидл» указан уровень 2, это означает, что сотрудник должен 
иметь фактическую оценку не ниже 2, чтобы компетенция считалась соответствующей грейду «Мидл».
Метод вычисления итогового грейда производится по методу доли навыков :
Для каждого грейда считаем долю навыков, где уровень сотрудника ≥ порога
Грейд — это  первый грейд, где доля ≥ 70% навыков
Так мы учитываем, что сотрудник должен быть сильным не в отдельных навыках, а в 
большинстве
Формула соответствия компетенции грейду
Компетенция считается соответствующей конкретному грейду, если:
Фактический уровень сотрудника по компетенции >= Требуемый уровень по этой компетенции для грейда
Иначе компетенция считается не соответствующей этому грейду.
Расчет доли соответствия грейду
Для каждого сотрудника отдельно рассчитывается доля компетенций, соответствующих каждому грейду.
Формула:
Доля соответствия грейду =
Количество компетенций, соответствующих грейду / Общее количество учитываемых компетенций
Пример:
Если сотрудник соответствует требованиям грейда «Мидл» по 39 компетенциям из 51:
39 / 51 = 76,47%
Правило присвоения итогового грейда
Итоговый грейд сотрудника определяется как самый высокий грейд, по которому сотрудник соответствует не менее чем 70% 
учитываемых компетенций.
Формула:
Итоговый грейд = максимальный грейд, где доля соответствия >= 70%
Проверка выполняется сверху вниз:
1. Сеньор
2. Мидл+
3. Мидл
4. Джун+
5. Стажер
Если сотрудник не достигает 70% по более высокому грейду, проверяется следующий ниже грейд.
Исключение компетенций из расчета
Для отдельных сотрудников из расчета исключаются компетенции, не относящиеся к их роли или зоне ответственности.
Для бизнес-аналитиков, аналитиков RnD и web-аналитиков не учитываются компетенции:
• Азы программирования 1С
• Понимание объектов метаданных 1С
• Хотя бы одна УХ / ERP / УТ
• Прочие конфигурации 1С
• Самописные конфигурации 1С

Исключенные компетенции:
• не считаются несоответствием;
• не входят в знаменатель;
• не влияют на итоговый грейд.
Интерпретация результата
Если сотрудник соответствует:
• ≥70% компетенций уровня «Сеньор» — присваивается грейд Сеньор
• ≥70% компетенций уровня «Мидл+» — присваивается грейд Мидл+
• ≥70% компетенций уровня «Мидл» — присваивается грейд Мидл
• ≥70% компетенций уровня «Джун+» — присваивается грейд Джун+
• ≥70% компетенций уровня «Стажер» — присваивается грейд Стажер
Логика ограничителей роста
Для анализа развития сотрудника дополнительно фиксируются компетенции, которые не соответствуют следующему грейду.
Формула:
Ограничитель = компетенция, по которой фактический уровень сотрудника < требуемого уровня следующего грейда
Такие компетенции используются для формирования индивидуального плана развития.
Учет soft skills
Soft skills  (например, аналитическое мышление, управление конфликтами, наставничество, работа в команде, 
ответственность, общительность, обучаемость, критическое мышление) . не учитываются при расчете итогового грейда
При расчете доли компетенций для грейда учитываются только  и технические/профессиональные hard skills
компетенции, релевантные роли сотрудника.
Уровень владения soft skills фиксируется отдельно в отчете, чтобы можно было видеть сильные стороны и зоны 
развития, но . не влияет на присвоение грейда
В отчете soft skills отображаются как отдельная колонка или лист, где указано фактическое значение (0–3) и текстовый 
уровень («Не знаю», «Знаю», «Использую», «Профи»).
